# 订阅管家 · 服务订阅管理

个人订阅服务管理工具，Linear Aesthetic 深色风格（青绿主题）。

## 功能

- **总览仪表盘**：月度支出、年化费用、活跃订阅数、即将到期、已过期
- **订阅管理**：添加/删除订阅（名称、分类、价格、周期、起止日期、备注）
- **8 大分类**：流媒体/云服务/软件/会员/新闻/存储/音乐/其他
- **计费周期**：月付/年付/周付/季付，自动换算月度成本
- **到期提醒**：7天内到期黄色预警、已过期红色标记
- **分类筛选**：chip 快速筛选
- **预设数据**：8 项常见订阅示例
- localStorage 持久化

## 技术

原生 HTML/CSS/JavaScript，零依赖单文件。
