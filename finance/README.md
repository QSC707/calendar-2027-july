# 财务管家 · 个人资产管理

个人财务管理网站，Linear Aesthetic 深色风格，管理收支、预算与未来投资规划。

## 功能

### 总览仪表盘
- 总资产、本月收入/支出/结余、投资总额
- 环比涨跌 + 储蓄率
- 收支趋势折线图（近6月，Canvas 绘制）
- 支出分类环形图（本月，Canvas 绘制）
- 最近记录列表

### 收支记录
- 添加收入/支出（金额、分类、日期、备注）
- 9 类支出 + 5 类收入，带 emoji 图标
- 按分类/类型筛选
- 悬停删除

### 预算管理
- 9 类支出月度预算
- 进度条 + 超支红色预警
- 本月已用 / 预算汇总

### 未来规划
- 储蓄目标（名称、目标金额、存入进度）
- 投资规划（名称、本金、预期年化）
- 投资收益预测（复利 10 年曲线，Canvas 绘制）

## 设计

- Linear Aesthetic：深色背景 + 玻璃拟态顶栏 + 靛蓝/紫色渐变
- 收入绿 #10b981 / 支出红 #f43f5e / 强调蓝 #6366f1
- Canvas 手绘图表（折线/环形/复利曲线），零依赖
- 卡片顶部彩条 + tab 下划线指示

## 技术

原生 HTML / CSS / JavaScript，Canvas 图表，localStorage 持久化，零依赖单文件。
