# 软木板 · 白板墙

拟物化软木板白板墙，像现实中一样在墙上粘贴卡片。Skeuomorphism 风格。

## 功能

- **便签**：6 种颜色（黄/粉/蓝/绿/紫/橙），双击编辑文字，带日期
- **照片**：输入图片 URL 或从示例选取，白边相框，双击编辑说明
- **待办清单**：勾选完成、双击编辑项、添加新项
- **拖拽移动**：鼠标 / 触屏拖拽，自动置顶
- **旋转**：随机倾斜角度，可手动重新旋转
- **置顶 / 删除**：悬停显示操作按钮
- **整理**：一键网格排列所有卡片
- **清空**：一键清空软木板
- **图钉**：8 种颜色随机分配，金属质感高光
- **持久化**：localStorage 保存所有卡片状态
- **预设内容**：首次打开自带欢迎便签、照片、待办

## 设计

- Skeuomorphism 拟物化：软木板颗粒纹理 + 木纹斜线
- 图钉：径向渐变金属球 + 高光 + 投影
- 便签：纸张光泽渐变 + 柔和阴影
- 照片：白边相框 + 胶片底注
- 待办：粉红标题栏 + 清单纸
- 工具栏：深色毛玻璃浮层

## 技术

原生 HTML / CSS / JavaScript，零依赖单文件部署。
