# 食历 · 一年菜单规划

以 **周** 为单位的全年食谱规划网站，Apple Minimalist 风格。

## 功能

- **12 个月份切换**：顶部箭头 / 月份 chip 快速跳转
- **按周分组**：每月自动按「周一→周日」划分为若干周
- **每日三餐**：早餐 / 午餐 / 晚餐，带食物 emoji
- **四季食材**：春笋、夏瓜、秋蟹、冬羊，随季节变换菜库
- **节日特餐**：春节饺子、端午粽子、中秋月饼、冬至羊肉等 10 个节日
- **今天高亮**：自动标记今日所在周与日
- **统计面板**：本月周数 / 规划天数 / 三餐总数 / 节日特餐数
- **响应式**：桌面 7 列网格，移动端横向滚动

## 设计

- Apple Minimalist：大量留白、SF 字体栈、毛玻璃顶栏
- 三餐色点：早餐金黄 / 午餐橙红 / 晚餐橄榄绿
- 周末浅橙底色、今日蓝色光带、节日玫红标签
- 周卡片交错淡入动画

## 技术

原生 HTML / CSS / JavaScript，零依赖单文件部署。
