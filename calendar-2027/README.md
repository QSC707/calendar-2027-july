# 2027 全年年历组件

精致深色风格年历，含实时时钟、季度视图与十二月份平铺展示。

## 特性

- 超深背景 + 靛蓝/紫色径向环境光晕
- 玻璃拟态卡片（backdrop-blur + 微边框 + 内嵌高光）
- shimmer 扫光动画 + 状态点呼吸动画
- 实时圆形模拟表盘时钟（指针随时间转动）
- 2027 全年 12 个月日历，按 4 季度 × 3 个月平铺展示
- 点击选中日期，高亮反馈
- 周末用强调色区分，等宽数字排版
- hover 靛蓝光晕、active 按压触感、选中态双层光晕

## 设计风格

采用 Linear Aesthetic（深色精密风格）设计语言，灵感来自 Linear 应用的视觉系统：

- **色彩体系**：以 `#080808` 超深背景为基底，靛蓝（`#6366F1`）与紫色（`#A855F7`）作为强调色，通过径向渐变在背景四角营造柔和的环境光晕
- **层次结构**：玻璃拟态卡片（`backdrop-filter: blur(24px)`）配合 1px 微边框（`rgba(255,255,255,0.08)`）和内嵌顶部高光，建立精致的深度层次
- **动效语言**：shimmer 扫光（7s 周期斜向移动）赋予卡片生命力；状态点呼吸动画（3s 缩放+透明度）暗示实时状态；时钟指针每秒平滑转动
- **排版精度**：`tabular-nums` 等宽数字确保日期列对齐；字间距 `-0.02em` 营造紧凑现代感

## 交互设计

- **日期选中**：点击任意日期，触发靛蓝-紫色渐变背景 + 双层光晕（24px + 48px）
- **悬停反馈**：hover 时叠加 18px 靛蓝柔光 + 边框增亮，提供层级感知
- **按压触感**：active 时 `scale(0.95)` 缩放，模拟物理按压反馈
- **周末区分**：星期表头与日期数字用靛蓝强调色微妙标记，不破坏整体协调
- **实时时钟**：圆形模拟表盘，时针/分针/秒针随系统时间实时转动

## 技术栈

纯 HTML / CSS / JavaScript，零依赖，单文件部署。

## 使用

浏览器直接打开 `calendar.html` 即可查看完整效果。

## 项目结构

```
huawei/
├── calendar-2027/             # 本项目
│   ├── calendar.html          # 全年年历组件（单文件，含全部样式与交互）
│   ├── README.md              # 项目说明
│   └── publish-config.json    # 发布配置（作品信息、凭证参数）
└── publish/                   # 共享发布工具（多项目复用）
    ├── publish-work.sh        # 一键发布脚本（接受项目名参数）
    ├── gen_sts.py             # STS 临时凭证生成
    ├── generate_cover.py      # 封面截图生成（Playwright）
    ├── pack_detail.py         # 详情包打包
    └── submit.py              # 提交到展览馆 API
```

## 发布

编辑 `calendar-2027/publish-config.json` 填写作品信息，然后在仓库根目录运行：

```bash
"C:\Program Files\Git\bin\bash.exe" publish\publish-work.sh calendar-2027
```

新增项目只需创建新文件夹（含 `html` + `README.md` + `publish-config.json`），然后指定项目名即可复用整套发布流程。
