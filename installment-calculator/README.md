# 分期价值计算器

分期贷款价值计算工具，支持等额本息/等额本金两种还款方式。

## 功能

- **两种还款方式**：等额本息（月供固定）、等额本金（月供递减）
- **实时计算**：本金/利率/期数滑块联动，参数变化即时更新
- **核心指标**：月供、总利息、总还款额、利息占比、本金占比
- **方式对比**：等额本息 vs 等额本金，利息差额一目了然
- **还款趋势图**：Canvas 绘制月供/本金/利息曲线，面积填充可视化
- **还款明细表**：逐期展示月供、本金、利息、剩余本金
- **预设方案**：房贷/公积金/车贷/消费贷一键填充
- **参数滑块**：本金、利率、期数均支持输入框+滑块双重调节

## 技术

原生 HTML/CSS/JavaScript，Canvas 绘图，零依赖单文件。
