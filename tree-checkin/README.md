# 种树打卡 · Tree Check-in

每日打卡种树，见证小树从种子长成参天大树的完整历程。

## 特性

- 8 个成长阶段：种子 → 发芽 → 幼苗 → 小树 → 中树 → 开花 → 结果 → 参天大树
- SVG 动态绘制树木，随打卡天数实时变化形态
- 每日打卡一次，localStorage 本地持久化
- 连续打卡天数统计 + 总天数统计
- 14 天打卡热力图，直观展示打卡规律
- 打卡成功粒子特效 + 阶段进化提示
- 进度条显示当前阶段成长进度
- 深色玻璃拟态风格，延续 Linear Aesthetic 设计语言

## 成长阶段

| 阶段 | 名称 | 所需天数 |
|------|------|----------|
| 1 | 种子 | 0 |
| 2 | 发芽 | 1 |
| 3 | 幼苗 | 3 |
| 4 | 小树 | 7 |
| 5 | 中树 | 15 |
| 6 | 开花 | 30 |
| 7 | 结果 | 60 |
| 8 | 参天大树 | 100 |

## 技术栈

纯 HTML / CSS / JavaScript + SVG，零依赖，单文件部署，localStorage 持久化。

## 使用

浏览器直接打开 `index.html` 即可开始打卡种树。
