# 十二星座 · Zodiac Signs

十二星座完整展示，含星座轮盘、四象分组、当前星座识别与详细性格分析。

## 特性

- 12 星座完整展示，按火土风水四象分组，每象 3 星座
- 星座轮盘：SVG 圆形 12 等分扇形，四象色彩分区，当前星座指示
- 当前星座自动识别（根据今日日期），卡片高亮 + 轮盘标记
- 每个星座含：简介、性格特质、优缺点、最佳配对、幸运色/数字
- 四象色系：火红 `#F87171` / 土绿 `#4ADE80` / 风蓝 `#38BDF8` / 水紫 `#A78BFA`
- 星空背景：60 颗闪烁星星 + 流星动画
- 点击卡片展开详情面板（底部滑出）
- 玻璃拟态卡片 + 渐变标题 + shimmer 扫光
