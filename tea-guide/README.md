# 泡茶科普 · Tea Guide

中国六大茶类科普与冲泡指南，含冲泡计时器、茶器介绍、泡茶小贴士。

## 特性

- 六大茶类：绿茶/白茶/黄茶/青茶/红茶/黑茶，含发酵程度与冲泡参数
- 冲泡指南：每种茶详细步骤（水温/茶水比/浸泡时间/注意事项）
- 冲泡计时器：选茶类自动设置建议时间，开始/暂停/重置/±5s
- 茶器一览：盖碗/紫砂壶/玻璃杯/煮茶壶等8种茶器介绍
- 泡茶小贴士：水温/茶水比/时间/温杯/水质/存茶6条实用建议
- 详情面板：点击茶卡展开完整信息
- 蒸汽动画背景 + 玻璃拟态卡片 + 渐变标题
- 暖色禅意主题：翡翠绿 + 琥珀色 + 金色
