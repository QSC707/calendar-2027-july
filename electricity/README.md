# 电费记录表 · 用电统计

电费记录与统计分析网站，Minimalist Modern 浅色风格，支持按年/季度/月维度查看用电情况。

## 功能

### 总览仪表盘
- 累计电费、累计用电量、均价/度
- 本年电费 + 同比涨跌
- 月均电费 + 最高月电费
- 月度电费趋势柱状图（近12月，Canvas）
- 用电量季度分布环形图（Canvas）
- 最近记录列表

### 记录管理
- 添加电费记录（年/月/用电量/金额/备注）
- 自动计算单价、防重复
- 按年份筛选、悬停删除

### 年度统计
- 年度电费对比柱状图（Canvas）
- 每年汇总卡片：总电费/总电量/月均/均价
- 季度迷你条形图

### 季度统计
- 选年份查看四季度电费
- Q1-Q4 季度卡片（金额/电量/月数）
- 季度对比柱状图（Canvas）

## 设计

- Minimalist Modern：浅色背景 + Electric Blue 渐变 + 悬浮卡片
- 四季配色：春绿/夏琥珀/秋红/冬青
- Canvas 手绘图表（柱状/环形），零依赖
- 卡片顶部彩条 + tab 下划线 + 悬浮阴影

## 技术

原生 HTML / CSS / JavaScript，Canvas 图表，localStorage 持久化，预设 2023-2026 示例数据。
