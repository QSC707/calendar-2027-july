# 照片墙 · Photo Wall

悬挂式照片展示网站，模拟现实生活中的挂绳照片墙，照片用木夹子悬挂在绳子上轻轻摇曳。

## 特性

- 悬挂展示：照片用木夹子挂在绳子上，模拟真实照片墙
- 摇曳动画：每张照片轻微摇摆，不同延迟营造自然感
- 随机倾斜：每张照片随机旋转 -4°~4°，自然不做作
- 悬停交互：鼠标悬停时照片摆正、放大、上浮，阴影加深
- 灯箱查看：点击照片打开大图灯箱，支持左右键翻页
- 拍立得风格：白边相框 + 手写体标题 + 日期
- 添加照片：40 种图标 + 16 种颜色选择，自定义标题和日期
- 随机排列：一键打乱照片顺序
- 预设数据：12 张回忆照片示例
- 数据持久化：localStorage 存储
- 暖色复古主题：琥珀色 + 金色 + 木夹子质感

## 技术栈

纯 HTML / CSS / JavaScript，零依赖，单文件部署。

## 使用

浏览器直接打开 `index.html` 即可查看。
