# 纸笺 · 日记本

个人日记记录工具，温暖纸质笔记本风格。

## 功能

- **日历浏览**：月历视图，有日记的日期标记圆点，点击筛选当日日记
- **写日记**：标题、正文、心情、天气、日期
- **8 种心情**：开心/平静/难过/生气/激动/幸福/疲惫/感恩，每种对应专属色彩
- **7 种天气**：晴/阴/雨/雪/雷暴/雾/风
- **自动标签**：根据内容关键词自动提取标签（运动/美食/工作/朋友/阅读/旅行/家人）
- **搜索功能**：按标题和内容全文搜索
- **心情筛选**：按心情快速筛选日记
- **统计面板**：总篇数、本月篇数、连续写作天数
- **日记详情**：弹窗查看完整内容，支持编辑和删除
- **预设示例**：5 篇示范日记
- localStorage 持久化

## 技术

原生 HTML/CSS/JavaScript，零依赖单文件。
