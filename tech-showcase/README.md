# 电子产品展示柜 · Tech Showcase

个人电子设备收藏与管理工具，展示购买信息与设备详情，数据本地持久化。

## 特性

- 设备展示柜：卡片网格展示所有电子设备，分类色彩标识
- 6 大分类：📱手机 / 💻电脑 / 🎧音频 / 📷相机 / ⌚穿戴 / 🔌其他
- 完整信息：名称、品牌、型号、价格、购买日期、购买渠道、状态、备注
- 3 种状态：🟢在用 / 🟡闲置 / 🔴已出
- 统计面板：设备总数、在用价值、累计投入、分类覆盖
- 搜索筛选：按名称/品牌搜索，按分类筛选，多种排序方式
- 添加/编辑/删除：模态框表单，分类选择器，状态切换
- 详情面板：点击卡片底部滑出完整信息
- 预设数据：8 台设备示例（iPhone/MacBook/AirPods/Sony 等）
- 数据持久化：localStorage 存储，刷新不丢失
- Linear Aesthetic 风格：深色精密 + 玻璃拟态 + 渐变标题 + 扫描线纹理

## 技术栈

纯 HTML / CSS / JavaScript，零依赖，单文件部署。

## 使用

浏览器直接打开 `index.html` 即可使用。
