# 喝水打卡 · Water Check-in

每日饮水量打卡追踪，可视化水杯 + 周统计图表，数据本地持久化。

## 特性

- 可视化水杯：SVG 绘制，水位动态填充 + 双层波浪动画 + 气泡上升
- 今日进度环：圆环进度条实时显示完成百分比
- 快速打卡：小杯 200ml / 标准 250ml / 大杯 350ml / 水瓶 500ml / 自定义滑块
- 撤销功能：一键撤销最近一次打卡
- 今日记录：时间线展示每次打卡时间和水量
- 本周统计：7 天柱状图，达标天数 / 总量 / 日均，悬停查看详情
- 每日目标可调：500-5000ml 范围自定义
- 数据持久化：localStorage 存储，刷新不丢失
- 海洋主题：深蓝渐变背景 + 上升气泡动画 + 玻璃拟态卡片

## 技术栈

纯 HTML / CSS / JavaScript + SVG，零依赖，单文件部署。

## 使用

浏览器直接打开 `index.html` 即可使用。
