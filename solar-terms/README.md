# 二十四节气 · Solar Terms

中国二十四节气可视化展示，含节气轮盘、四季分区、当前节气高亮与物候诗意的完整呈现。

## 特性

- 24 节气完整展示，按春夏秋冬四季分组，每季 6 节气
- 节气轮盘：圆形 24 等分扇形，四季色彩分区，当前节气指示
- 当前节气自动识别（根据今日日期），卡片高亮 + 轮盘标记
- 每个节气附物候诗意描述（三候）
- 四季中国传统色系：春青绿、夏朱红、秋金黄、冬墨蓝
- 距下一节气倒计时天数
- 玻璃拟态卡片 + 渐变标题 + shimmer 扫光
- 响应式布局，移动端 2 列 / 桌面端 3 列

## 二十四节气

| 季 | 节气 |
|----|------|
| 春 | 立春 · 雨水 · 惊蛰 · 春分 · 清明 · 谷雨 |

| 秋 | 立秋 · 处暑 · 白露 · 秋分 · 寒露 · 霜降 |
